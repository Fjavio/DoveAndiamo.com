Installazione pacchetti:

1. Scarica i Build Tools: https://visualstudio.microsoft.com/visual-cpp-build-tools/ e clicca su "Scarica Build Tools".

2. Avvia l'installer: Apri il file .exe appena scaricato.

3. Seleziona il pacchetto: Nella schermata principale dell'installer, metti la spunta sulla casella "Sviluppo per desktop con C++". Sulla destra vedrai che selezionerà in automatico alcuni pacchetti (tra cui MSVC v143 e l'SDK di Windows 10/11). Lasciali così.

4. Installa

5. Una volta finita l'installazione, chiudi completamente VS Code (o il terminale PowerShell che stai usando) e riaprilo.

6. In cartella backend, riattiva l'ambiente e lancia di nuovo: pip install -r requirements.txt
